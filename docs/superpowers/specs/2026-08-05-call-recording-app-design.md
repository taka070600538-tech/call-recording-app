# 通話自動録音アプリ 設計書

## 背景・目的

Android（Pixel）で電話の通話を自動で録音し、あとで選んだものだけ文字起こしして、テキストと音声をGitHub経由でObsidian Vaultに取り込めるようにしたい。用途は自分用のメモ・備忘録（診療関連の通話は対象外）。

既存の `Git/voice-diary-app`（PWA＋Web Speech API＋GitHub保存）と同じ「スマホで記録→GitHub保存→PC側で自動pull・整理」の流れを踏襲するが、通話録音はブラウザから実現できないため、今回はネイティブAndroidアプリとして作る。

## 技術的前提（重要な制約）

- Pixel（AOSP系）は `MediaRecorder.AudioSource.VOICE_CALL` へのアクセスをOSレベルでブロックしており、通話音声そのものを直接録音することはできない。
- そのため、**通話を自動でスピーカーホンにし、端末のマイクで周囲音（自分の声＋スピーカーから出る相手の声）を録音する方式**を採用する。全機種で確実に動作するが、音質は通話音声を直接録るより劣る。
- 通話録音アプリは Google Play の審査ポリシー上配布が難しいため、Playストアには公開せず、ビルドしたAPKをADB等で直接インストールする。

## アーキテクチャ

### 1. 自動録音エンジン（Androidアプリ本体）

- `BroadcastReceiver` で `TelephonyManager` の通話状態変化（`RINGING` → `OFFHOOK` → `IDLE`）を検知する。
- `OFFHOOK`（通話開始）を検知したら:
  - `AudioManager.setSpeakerphoneOn(true)` でスピーカーホンを自動ON
  - フォアグラウンドサービスを起動し、`MediaRecorder`（`AudioSource.MIC`）で録音開始
- `IDLE`（通話終了）を検知したら、録音を停止し、端末内にファイルを保存してサービスを終了する。
- ファイル名は日時ベース（例：`2026-08-05-1430.m4a`）。電話番号取得は追加の権限（`READ_CALL_LOG`等）が必要になるため、初期スコープでは含めない。

### 2. 録音一覧画面

- 端末内に保存された録音の一覧を表示（再生・削除が可能）。
- 各録音に「文字起こし」ボタンを配置。押したものだけが次のフローに進む（全件自動文字起こしはしない＝コスト・手間のコントロール）。

### 3. 文字起こし＆GitHub連携

- 「文字起こし」を押すと、対象の音声ファイルを OpenAI Whisper API に送信してテキスト化する。
- APIキーはアプリ内の設定画面で入力し、端末に保存する（`voice-diary-app` の GitHub PAT と同様の方式）。
- 文字起こし結果は確認・編集できる画面を表示する。
- 「GitHubに保存」を押すと、以下をまとめて実行する:
  - `diary/YYYY-MM-DD.md` に時刻見出し付きでテキストを追記（`voice-diary-app` と同じ形式）
  - `diary/audio/YYYY-MM-DD-HHMM.m4a` として元の音声ファイルをアップロードし、Markdown側からリンクする
- GitHub認証は Personal Access Token 方式（`voice-diary-app` と同じ）。

### 4. PC側自動同期

- 新規GitHubリポジトリ `call-recording-app` を作成し、上記の `diary/` 構成を保存先とする。
- `日記/pull-diary.ps1` と同じ構成の同期スクリプトを作り、`日記/通話録音` フォルダにMarkdownを自動整理・転記する。
- 既存の `pull-diary.ps1` 同様、スケジュールタスクとして定期実行する。

## 必要な権限

| 権限 | 用途 |
|---|---|
| `RECORD_AUDIO` | 通話中の録音 |
| `READ_PHONE_STATE` | 通話状態（着信・応答・終了）の検知 |
| `INTERNET` | Whisper API・GitHub API呼び出し |
| フォアグラウンドサービス関連権限（`FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MICROPHONE` 等）／通知権限 | Android 14+ でのバックグラウンド録音に必須 |

## エラーハンドリング

- `RECORD_AUDIO` / `READ_PHONE_STATE` が未許可の場合、自動録音は動作しない旨を明示する画面を表示する。
- Whisper API呼び出し失敗（ネットワーク不通・キー不正等）時はエラーを表示し、音声ファイルは失わず再試行できるようにする。
- GitHub保存失敗時もテキストの下書きを保持し、再試行できるようにする。
- 端末のストレージ残量が少ない場合、録音開始前に警告する。

## 配布方法

- Google Playストアには公開しない。
- Android Studioでビルドした APK を USB/ADB 経由でPixel実機に直接インストールする。

## テスト方針

- Whisper連携・GitHub保存（テキスト＋音声アップロード）は、サンプル音声ファイルを使って実機の通話なしに事前検証できる。
- 自動録音（スピーカーホン自動ON→マイク録音→通話終了で自動停止、および実際に相手の声が聞き取れる音質で録れているか）は、Pixel実機での実際の発着信によってのみ検証可能。実装後に実通話でテストする。

## スコープ外（今回はやらないこと）

- 通話音声（`VOICE_CALL`）への直接アクセス（Pixelでは技術的に不可能）
- 電話番号・発信者名の自動取得によるファイル命名
- 全録音の自動文字起こし（手動トリガーのみ）
- 診療・患者対応に関する通話への利用（本アプリは個人用メモ目的に限定）

## 法的な留意点（参考情報であり法的助言ではない）

自分が当事者である通話を録音すること自体は、日本国内では一般に個人利用の範囲で問題になりにくいとされているが、これは一般的な参考情報であり法的助言ではない。個別の状況について懸念がある場合は専門家に相談すること。
